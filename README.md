# MonitoringAgent

Консольный агент мониторинга активности пользователя на C++17 (Windows, Win32 API).
Тестовое задание «Разработка системного агента мониторинга (C++)».

## Что делает

Каждые 5 секунд собирает: имя процесса и заголовок активного окна
(`GetForegroundWindow`, `QueryFullProcessImageName`), а также факт активности
ввода за последние 5 секунд (`GetLastInputInfo`, без перехвата нажатий).

Снимки копятся в потокобезопасном буфере (лимит 100 записей). Отдельный поток
раз в 30 секунд (или при накоплении 10 записей) упаковывает буфер в JSON и
отправляет POST-запросом на `http://localhost:8080/`. Если сервер недоступен —
данные не теряются, возвращаются в буфер и отправляются повторно позже.

При Ctrl+C / закрытии консоли (`SetConsoleCtrlHandler`) все неотправленные
записи сохраняются в `backup.json` рядом с исполняемым файлом.

## Стек

C++17, CMake (зависимости — cpp-httplib и nlohmann/json — подтягиваются
автоматически через `FetchContent`).

## Сборка

Открыть папку проекта в Visual Studio (`Файл → Открыть → Папку`) — CMake
настроится автоматически при первом открытии (нужен интернет для загрузки
зависимостей). Выбрать конфигурацию `x64-Debug` или `x64-Release` и собрать
через `Ctrl+Shift+B`. Исполняемый файл появится в
`out/build/<конфигурация>/MonitoringAgent/MonitoringAgent.exe`.

## Проверка

1. Запустить тестовый сервер: `python -m http.server 8080`
2. Запустить `MonitoringAgent.exe`
3. Подождать 30 секунд — в консоли сервера появятся входящие POST-запросы
4. Нажать Ctrl+C в окне агента — рядом с `.exe` появится `backup.json` с
   оставшимися неотправленными записями (если они были)
